# ربات سیگنال‌دهی هوشمند ارز دیجیتال (تلگرام)

ربات تلگرامی که به‌صورت خودکار:

- **کل بازار USDT بایننس** را با فیلتر نقدشوندگی اسکن می‌کند (نه چند کوین ثابت — همه‌ی جفت‌ارزهای فعال و نقدشونده).
- در **۴ تایم‌فریم هم‌زمان** (۱۵ دقیقه / ۱ ساعت / ۴ ساعت / روزانه) روند و شتاب قیمت را می‌سنجد.
- از ترکیب EMA، RSI، MACD، بولینگر باند، ATR، حجم معاملات، و سطوح حمایت/مقاومت یک **امتیاز اطمینان ۰ تا ۱۰۰** می‌سازد.
- فقط وقتی امتیاز از آستانه تنظیم‌شده بالاتر برود، سیگنال با **نقطه ورود، حد ضرر، و سه هدف قیمتی (TP1/TP2/TP3)** در تلگرام ارسال می‌کند.
- در صورت فعال‌سازی، هر سیگنال را با یک توضیح کوتاه از Claude (بر پایه همان اعداد محاسبه‌شده، نه حدس) همراه می‌کند.

## ⚠️ قبل از هر چیز
این ابزار **توصیه مالی نیست**. هیچ سیستمی — چه مبتنی بر قوانین، چه هوش مصنوعی — نمی‌تواند حرکت قیمت را با قطعیت پیش‌بینی کند. حتماً:
1. اول با **حساب دمو / کاغذی (paper trading)** چند هفته تست کنید.
2. آستانه امتیاز و پارامترهای ریسک را متناسب با تحمل ریسک خودتان تنظیم کنید.
3. هرگز بیش از چیزی که توان از دست دادنش را دارید، ریسک نکنید.

## نصب

```bash
cd ai_signal_bot
python -m venv venv
source venv/bin/activate      # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
```

## ساخت ربات تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید و با دستور `/newbot` یک ربات جدید بسازید — یک **توکن** به شما می‌دهد.
2. با ربات خودتان یک پیام بفرستید (مثلاً `/start`)، سپس با مرورگر این آدرس را باز کنید تا `chat_id` خودتان را پیدا کنید:
   ```
   https://api.telegram.org/bot<TOKEN>/getUpdates
   ```
   یا از [@userinfobot](https://t.me/userinfobot) استفاده کنید. اگر می‌خواهید سیگنال‌ها در یک کانال ارسال شوند، ربات را ادمین کانال کنید و از آی‌دی عددی کانال (با `-100` در ابتدا) استفاده کنید.

## تنظیم متغیرهای محیطی

```bash
export TELEGRAM_BOT_TOKEN="123456:ABC-your-token"

# اختیاری — برای فعال‌سازی توضیح هوش مصنوعی روی هر سیگنال

```

در ویندوز (PowerShell): `$env:TELEGRAM_BOT_TOKEN="..."`

## اجرا

```bash
python main.py
```

ربات بلافاصله یک اسکن کامل بازار انجام می‌دهد، سپس هر `SCAN_INTERVAL_SECONDS` (پیش‌فرض ۱۵ دقیقه) دوباره اسکن می‌کند. با دستور `/scan` در چت ربات هم می‌توانید اسکن دستی بزنید، و با `/status` وضعیت را ببینید.

## تنظیمات مهم (`config.py`)

| متغیر | توضیح |
|---|---|
| `MIN_24H_QUOTE_VOLUME_USDT` | حداقل حجم ۲۴ساعته برای اینکه کوین وارد اسکن شود (فیلتر کوین‌های بی‌ارزش) |
| `MAX_SYMBOLS_PER_CYCLE` | سقف تعداد نماد در هر چرخه اسکن (برای رعایت rate limit بایننس) |
| `SCAN_INTERVAL_SECONDS` | فاصله زمانی بین اسکن‌ها |
| `MIN_SIGNAL_SCORE` | حداقل امتیاز اطمینان برای صدور سیگنال (هرچه بالاتر، سیگنال کمتر ولی باکیفیت‌تر) |
| `FACTOR_WEIGHTS` | وزن هر فاکتور تحلیلی در امتیاز نهایی |
| `ATR_STOP_MULTIPLIER` | فاصله حد ضرر بر حسب ضریب ATR |
| `TP_R_MULTIPLES` | اهداف قیمتی بر حسب واحد ریسک (R) — پیش‌فرض ۱R / ۲R / ۳.۵R |
| `SIGNAL_COOLDOWN_HOURS` | جلوگیری از ارسال تکراری سیگنال یک نماد در این بازه زمانی |

## ساختار پروژه

```
ai_signal_bot/
├── config.py          تنظیمات مرکزی
├── indicators.py       محاسبه اندیکاتورهای تکنیکال (بدون وابستگی به ta-lib)
├── market_data.py       دریافت داده از API عمومی بایننس
├── signal_engine.py     منطق امتیازدهی و ساخت پلن معامله (ورود/استاپ/تارگت)
├── ai_analysis.py        لایه اختیاری توضیح هوش مصنوعی (Claude)
├── state.py             جلوگیری از سیگنال تکراری
├── telegram_bot.py       فرمت پیام و ارسال به تلگرام + دستورات
├── main.py               نقطه ورود و اجرای حلقه اصلی
└── requirements.txt
```

## توسعه بیشتر (پیشنهادها)

- اضافه‌کردن صرافی‌های دیگر (Bybit، OKX) با یک ماژول `market_data` جدید.
- اتصال به دیتابیس برای نگهداری تاریخچه سیگنال‌ها و محاسبه Win Rate واقعی.
- افزودن دکمه‌های اینلاین تلگرام (مثلاً «این سیگنال را دنبال کن») برای ردیابی خودکار نتیجه معامله.
- اجرای ربات به‌صورت دائمی روی یک VPS یا سرویس‌هایی مثل Railway/Render با `systemd` یا Docker.
